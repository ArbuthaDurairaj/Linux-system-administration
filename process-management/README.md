# Process Management

## Overview

This section covers monitoring, controlling, and managing running processes in Linux.

## Topics Covered

* Viewing active processes
* Background and foreground jobs
* Process termination
* System monitoring

## Common Commands

```bash
ps
top
kill
kill -9
jobs
bg
fg
```

## Learning Outcomes

* Monitor system processes.
* Identify resource usage.
* Manage running applications.
* Terminate unresponsive processes.

## Skills Demonstrated

* Linux Process Management
* System Monitoring
* Troubleshooting
