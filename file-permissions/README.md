# File Permissions

## Overview

This section demonstrates Linux file permission management, ownership, and access control using command-line utilities.

## Topics Covered

* File permissions
* Directory permissions
* Ownership
* Groups
* Umask
* RWX permission calculations

## Common Commands

```bash
ls -l
chmod
chown
chgrp
umask
```

## Learning Outcomes

* Understand Linux permission bits.
* Modify file and directory permissions.
* Change file ownership and group assignments.
* Configure default permissions using `umask`.
