# Shell Scripting

## Overview

This section contains Bash shell scripting exercises demonstrating Linux automation and scripting fundamentals.

## Topics Covered

* Bash script creation
* Variables and user input
* Conditional statements (`if`, `elif`, `else`)
* Loops (`for`, `while`)
* Functions
* File operations
* Script permissions and execution

## Common Commands

```bash
chmod +x script.sh
./script.sh
bash script.sh
```

* Write executable Bash scripts.
* Automate repetitive tasks.
* Accept user input and process data.
* Implement decision-making and looping structures.
* Improve command-line productivity.
