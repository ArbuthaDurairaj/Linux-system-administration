# Networking

## Overview

This section demonstrates basic Linux networking commands used for connectivity testing, network configuration, and troubleshooting.

## Topics Covered

* Network configuration
* IP address management
* Connectivity testing
* Host information

## Common Commands

```bash
ip addr
hostname
ping
ss
netstat
```

## Learning Outcomes

* View network interfaces.
* Verify network connectivity.
* Display host information.
* Troubleshoot network issues.

## Skills Demonstrated

* Linux Networking
* Network Troubleshooting
* System Diagnostics
