# Linux Networking

## Overview

This section demonstrates common Linux networking commands used for network configuration, diagnostics, and troubleshooting.

## Common Commands

### Display IP Address

```bash
ip addr
```

### Display Hostname

```bash
hostname
```

### Display Host IP

```bash
hostname -I
```

### Test Network Connectivity

```bash
ping google.com
```

### View Active Network Connections

```bash
ss -tuln
```

### Display Routing Table

```bash
ip route
```

### Display Network Interfaces

```bash
ip link
```

## Learning Outcomes

- View IP configuration
- Test network connectivity
- Identify active interfaces
- Inspect network routes
- Troubleshoot basic network issues
